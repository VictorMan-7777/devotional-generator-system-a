Operator is planning a presale website using Vercel. A website design agent will be spun up to interact with Claude so the site tracks with DevG system state.

**Structure:**
- Home page (marketing/landing)
- Devotionals page (presale)

**Products:**
- Base: PDF devotional volume — all buyers receive this (instant delivery)
- Add-on: Hard copy — optional upsell at checkout; batch printed when order threshold is reached

**Fulfillment model:**
- PDF: immediate digital delivery
- Hard copy: batch model — collect add-on orders, trigger print run at threshold (e.g. 50 copies), ship via POD (IngramSpark) or batch printer + fulfillment
- Checkout: Stripe preferred (supports base product + add-on line items, can track batch orders)

**Why:** Operator shifting from digital-first to presell-then-print. PDF validates demand with zero fulfillment risk; hard copy add-on serves buyers who want physical copy without requiring a minimum upfront.

**Cover design:**
- New design agent (not pdf_art_director — different brief, marketing vs. layout)
- No color direction established yet — existing DevG work has been b/w; cover design starts fresh with no constraint
- Agent must present 3+ options per concept with rationale (operator preference for options)
- Informed by pdf_art_director's typography/layout decisions but not constrained by them
- Works for both PDF cover and KDP print without a separate design pass

**Preview strategy:**
- Week 1 of the most recent volume offered as a free preview
- Gated behind email capture: user enters email → PDF sent to that address (implicit verification — must use real email to receive content)
- Transactional email needed: Resend preferred (clean Vercel/Next.js integration), or Postmark/SendGrid
- Can also be inline reader on the devotionals page
- Preview PDF generated by the same pipeline + PDF export — no manual assembly

**How to apply:** When website design agent asks about site scope, this is the full picture. Home page drives to devotionals page; devotionals page has free preview + paid product with hard copy add-on. Stripe for checkout.
