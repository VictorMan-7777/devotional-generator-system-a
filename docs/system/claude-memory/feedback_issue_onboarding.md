When starting work on any issue (bug, feature, task), always read these files first before describing or tackling the issue:

1. `docs/system/outliner-integration-transfer.md`
2. `docs/system/outliner-execution-handoff.md`
3. `docs/system/outliner-agent-redesign-spec.md`

These give a new session everything it needs to understand the system state, what was done, and why.
