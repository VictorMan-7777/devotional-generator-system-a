# Open-Source Biblical Resource Scouting

## Purpose

When the general librarian is not fully occupied with active acquisition or card
work, idle time should be used to scout additional open-source/public-domain
biblical resources that fit the current DevG theological lane.

This is not a live card catalog.
It is a scouting list for future acquisition.

## Current theological fit

The current library and cuttings already lean toward a Protestant,
public-domain, evangelical/Reformed-friendly reference lane.

That fit is an inference from the resources already in use, such as:
- Matthew Henry
- John Owen
- Thomas Watson
- John Bunyan
- Jonathan Edwards
- Easton
- Smith
- ISBE

So the priority is not "all open resources."
The priority is resources that are:
- public-domain or otherwise openly accessible
- stable enough for repeated research use
- broadly consistent with the current Protestant reference lane
- useful for outline, exposition, term/background, or quote/citation work

## Scouted resource candidates

### CCEL public-domain classics

Use case:
- high-value shelf for classic Protestant commentaries and dictionaries
- especially strong for commentary and reference works already named in the system

Strong candidates:
- Matthew Henry's Commentary on the Whole Bible
  - <https://www.ccel.org/h/henry/mhc2/MHC00000.HTM>
- Easton's Bible Dictionary
  - <https://www.ccel.org/e/easton/ebd/ebd.html>
- Smith's Bible Dictionary
  - <https://www.ccel.org/s/smith_w/bibledict/cache/bibledict.html3>
- Philip Schaff, *A Dictionary of the Bible*
  - <https://www.ccel.org/ccel/schaff/dictionarybible.html>

Why it fits:
- public-domain
- stable
- already aligned with the current resource mix
- useful for research librarian fulfillment and future acquisition

### Archive.org public-domain scans

Use case:
- strong for holding the actual parent book when full scans, OCR text, EPUB, or
  bibliographic metadata are needed
- especially valuable for quote/citation completeness

Why it fits:
- large public-domain holdings
- often includes publication metadata, page images, OCR text, EPUB, and PDF
- useful when quote selector needs full Turabian fields

Current observation:
- Archive is already proving useful for parent-resource acquisition
- but title-family confusion is real, so librarian review is still required

### International Standard Bible Encyclopedia (1915)

Likely source family:
- Archive.org scans of multi-volume editions

Why it fits:
- classic Protestant reference work
- useful for background and term work
- already in the current excerpt cuttings

Risk:
- editions vary
- the research librarian should prefer the historically appropriate public-domain
  edition rather than any later unrelated reprint

### Jamieson-Fausset-Brown Bible Commentary

Likely source family:
- public-domain scans and text mirrors

Why it fits:
- already in the current excerpt cuttings
- consistent with the current Protestant commentary lane
- useful for whole-Bible exposition and background

Risk:
- many mirrors and reprints exist
- the general librarian should verify that the holding actually corresponds to
  the commentary family, not just a modern commercial edition page

### John Gill's Exposition of the Bible

Likely source family:
- public-domain text mirrors
- archive scans where available

Why it fits:
- already in the current excerpt cuttings
- consistent with the current library lane
- valuable for verse-level exposition support

Risk:
- many online hits are fragments, audio readings, or scraped mirrors
- the general librarian should prioritize a stable full-work source

## Idle-duty source order

When the general librarian is scouting new resources, prefer this order:

1. Resources already named in the PRD / current cuttings / existing library lane
2. Stable CCEL public-domain holdings
3. Archive.org parent scans with usable metadata
4. Other public-domain/open sources only after the first three are exhausted

## Research-librarian implications

Once these resources are actually acquired and carded:
- the research librarian can answer more requests from shelf-ready holdings
- the quote selector can increasingly rely on librarian-served resources
- the outliner and exposition writer can request researched cuttings instead of
  depending on ad hoc retrieval

## Note

These are scouting candidates, not live shelf cards.
No resource moves into the live library until:
1. the parent resource is acquired,
2. the librarians draft a card,
3. the card is evaluated,
4. the card is accepted.
