# Library Card Evaluation Rubric

## Purpose

This rubric evaluates whether a librarian-created card is shelf-ready for the
live catalog.

No live card should be accepted until:
- the resource is actually in the library
- the card has been reviewed against this rubric

If the card is weak, the librarians receive feedback and recreate it.

## Evaluation questions

1. Is the resource actually in the library?
- `pass` only if acquired and available
- `fail` if the card describes an unacquired book

2. Does the card identify the resource clearly?
- title
- author/editor
- resource type

3. Does the card show what the resource contains?
- not just the title
- not just the TOC label
- should reflect actual contents such as:
  - section outlines
  - verse commentary
  - introductions
  - term/background articles
  - citation metadata

4. Does the card say what research needs the resource serves?
- outline
- structure
- exposition
- terms
- background
- quotes
- citation
- genre help

5. Is the card honest about limits?
- avoids overstating what the resource can do
- does not claim outline help if none is actually present

6. Is the card useful to the research librarian?
- could the research librarian decide whether to consult this resource for a
  real request?

## Decision outcomes

- `accepted`
  - card can move into the live catalog
- `revise`
  - librarians get feedback and recreate the card
- `reject`
  - resource or card is not ready for live use

## Feedback format

When a card fails review, feedback should include:
- what was missing
- what was overstated
- what additional inspection is needed
- whether the problem is:
  - acquisition incomplete
  - metadata incomplete
  - content understanding weak
  - worker-role mismatch
